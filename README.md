# Banking Data Platform using PySpark

## Overview

This project demonstrates the design and implementation of a production-style Banking Data Platform using PySpark and the Medallion Architecture (Bronze, Silver, and Gold layers). It is being developed as a hands-on learning project to understand PySpark, Spark internals, data engineering best practices, and analytics-ready data modeling.

The project simulates a real banking environment by ingesting customer, account, transaction, merchant, branch, and exchange rate data. It covers the complete data engineering lifecycle, including data ingestion, transformation, data quality validation, star schema design, performance optimization, and documentation.

The implementation is developed in Google Colab using PySpark, while the repository serves as both a portfolio project and an educational resource for aspiring and experienced data engineers.
